# openMouse：使用指南

openMouse 让每个已连接的鼠标在同一个 Windows 桌面上拥有各自的指针。两个人可以同时使用
一台电脑，各用各的鼠标：一个人在这里点击，另一个人在那边滚动页面。

## 开始之前

- openMouse 会用彩色指针取代 Windows 的箭头，每个鼠标一种颜色。默认情况下，第一个指针
  是黄色，第二个是橙色。
- 同一时间只能有一个人打字：Windows 只会把按键发送给当前活动的窗口。鼠标彼此独立，
  键盘则不然。
- 需要 64 位的 Windows 10 或 11，以及至少两个鼠标（笔记本电脑的触摸板算作一个）。

## 1. 启动

1. 运行 `openmouse.exe`。无需安装。
2. Windows 会请求管理员权限：请选择允许。没有它，openMouse 仍可工作，但以“管理员身份”
   启动的窗口（例如任务管理器）将不受鼠标控制。
3. 时钟旁边会出现一个图标，屏幕上会出现两个不同颜色的指针。

若要随 Windows 启动：点击图标，选择**设置…**，进入**常规**选项卡，勾选**随 Windows 启动
openMouse**。只有把 openMouse 安装到受保护的文件夹（例如 `Program Files`）之后才能这样
做，因为此时程序会以完全权限启动；如果程序位于其他文件夹（下载、桌面……），该复选框为灰色，
窗口中会有相应说明。

## 2. 连接两个鼠标

只需插入第二个鼠标：一个不同颜色的新指针就会出现。拔出鼠标后，它的指针会消失；重新
插入后，指针会回到它停下的位置。最后一个指针永远不会被隐藏，因此您不会没有指针可用。

每个鼠标都会保留自己的颜色，即使把它插到另一个 USB 接口也一样。

如果两个指针互换了，或者某个鼠标控制了错误的指针（无线接收器有时会这样），请拔下并重新
插上该鼠标的接收器，然后打开**设置…**查看已识别的鼠标。

## 3. 使用两个鼠标

- **移动**：每个鼠标移动各自的指针，互不干扰。
- **点击**：点击发生在进行点击的那个鼠标所指的位置。点击一个非活动窗口会激活它，并且
  一次点击就完成操作。
- **滚动**：滚轮滚动的是自己指针下方的窗口，无需先点击。
- **拖动**（移动文件、选择内容）：当一个人按住按键时，另一个人的点击会等到这个动作结束
  后再执行。在此期间两个指针仍可自由移动。
- 鼠标的**后退键和前进键**也能使用，各自对应各自的鼠标。

## 4. 设置

点击时钟旁边的图标，然后选择**设置…**。窗口有两个选项卡（可用 **Ctrl + Tab** 切换）。每项
更改都会立即应用并保存；**撤销我的更改**会恢复打开窗口时鼠标的各项数值。这两个按钮和状态栏
（“已应用并保存。”）位于窗口底部，两个选项卡共用。

### “常规”选项卡

- **随 Windows 启动 openMouse**：参见上文“启动”。
- **语言**：“自动（Windows 语言）”“Français”“English”“Deutsch”“Español”“Русский”“简体中文”或
  “العربية”。所选语言会立即应用于窗口、图标菜单和 openMouse 的提示信息，并会被记住。
- **帮助**：在 GitHub 上以所选语言打开本指南。
- **关于**：制作人员名单，以及 Calepitool 网站的链接。

### “鼠标”选项卡

每个鼠标一个区域，笔记本电脑的触摸板另有一个区域。把指针移到**固定灵敏度**、**渐进加速**
或**学习按键**上，会显示一条简短的提示。

### 识别和禁用鼠标

每个区域的标题会显示鼠标的品牌（“Logitech 鼠标”），品牌从鼠标本身读取；读取不到时，则使用
其制造商的名称。如果无法读取品牌，标题就保持为带编号的“鼠标”；同一品牌的两个鼠标也会带上
编号。

标题右侧的**禁用**复选框可以把鼠标搁置一旁而不必拔出它：它的指针会消失，它所做的一切操作
也会立即被忽略。取消勾选后，鼠标会回到它停下的位置，颜色和速度不变。最后一个可用的鼠标无法
被禁用（触摸板在使用期间也算在内）：openMouse 会拒绝，以免您没有指针可用。

### 指针外观

- **颜色**：十种颜色，让您一眼认出自己的指针。
- **指针样式**：经典、亮色边缘（最醒目，为默认样式）、白色填充配彩色边缘、大号，或柔和光晕。
  预览会在四种背景上显示效果。

### 指针速度

每个鼠标使用两种模式之一（另一种模式的滑块呈灰色）：

- **固定灵敏度**：每次移动都乘以相同的数值。这是最简单的方式：如果指针太慢，就调大数值。
- **渐进加速**：小幅动作慢（精确），大幅动作快（跨越屏幕）。**加速阈值**决定从何处开始加速。

**默认值**会恢复初始设置。

### 限制在屏幕内

您可以把每个鼠标的指针限制在一块屏幕内（当每个人使用各自的显示器时很方便），也可以让它
在整个桌面上自由移动。

### 学习按键

鼠标有时带有 Windows 不认识的按键。点击**学习按键**，然后在八秒内按下该按键。之后选择它的
功能：点击（左键、右键、中键、后退、前进）、键盘快捷键，或不执行任何操作。点击发生在这个
按键所属鼠标的指针所在位置。**忘记**会删除所选的按键。

有些按键无法学习：只有厂商软件才能读取的按键不会向 Windows 发送任何信息。窗口会告诉您
这一点。

## 5. 出现问题时

| 问题 | 解决办法 |
|---|---|
| 没有指针，或指针一直隐藏 | 按 **Ctrl + Alt + Shift + Q**：openMouse 会停止并交还 Windows 的指针。否则运行 `openmouse.exe --restore-cursor`。 |
| 按下 Ctrl + Alt + Del 或锁定会话之后 | 这是正常的：此时由 Windows 接管。返回后 openMouse 会自动恢复工作。 |
| 管理员窗口不响应鼠标 | 重新启动 openMouse，并同意管理员权限。 |
| 指针跟随了错误的鼠标 | 重新连接该鼠标，然后在**设置…**中检查已识别的鼠标。 |
| 其他任何情况 | 在图标菜单中选择**打开日志文件夹**：`openmouse.log` 会告诉您发生了什么。 |

## 6. 已知限制

- **同一时间只有一个键盘处于活动状态。** 两个人无法同时在两个不同的窗口中打字。
- **任务栏、“开始”菜单和通知。** 在这些位置只能看到当前“拥有”真正 Windows 指针的那个鼠标的
  指针。另一个指针会从它们后面穿过：要使用它们，请先用那个鼠标在普通窗口中点击一下，或者让
  另一个人来操作。
- **直接在非活动窗口中开始的拖动**会丢失：先点击一次激活窗口，再进行拖动。
- **同时滚动**：如果两个人在同一时刻滚动，滚轮的某一步有时会落到另一个窗口上。
- 声音、剪贴板和窗口的叠放顺序仍由两人共用。
